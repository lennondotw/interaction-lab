# Chat behavior contracts

These are intentional observable behaviors, including interruption and intermediate frames. Tests
should preserve them when implementation details change. See [verification](./verification.md) for
the runner and evidence limits; script names below refer to `scripts/test-chat-*.mjs`.

## Boundaries

Convergence assumes a mounted viewport, finite layout changes, and no later user cancellation. A real
user interruption intentionally ends the flight rather than preserving its projected destination.
Geometry tolerances account for browser scroll rounding; they do not allow state regressions such as
`following` briefly becoming `detached` during a native clamp.

The 10,000-row check bounds layout-manager geometry reads, not total React render time or browser frame
cost. These tests do not establish virtualization support, arbitrary-item exit animation, universal
trackpad behavior, or cross-browser equivalence. CI runs Chromium; native trackpad inertia and other
browser engines still require separate validation.
